# FOSS tools by discipline

This is a reference, not a complete list. For each tool listed, the source code is publicly available and the tool is actively maintained.

| Discipline | FOSS tool | Replaces | Used at |
|-----------|----------|---------|--------|
| CS / IT | [Ubuntu](https://ubuntu.com) / [Fedora](https://fedoraproject.org) | Windows | [Kerala KITE](https://kite.kerala.gov.in/KITE/index.php/welcome/downloads), [IIT Bombay](https://fossee.in/sdes-iitb/install_linux.html) |
| CS / IT | [VSCodium](https://vscodium.com), [Vim](https://www.vim.org), [Emacs](https://www.gnu.org/software/emacs/) | Proprietary IDEs | Industry standard |
| CS / IT | [Git](https://git-scm.com) | Proprietary VCS | Standard globally |
| CS / IT | [PostgreSQL](https://www.postgresql.org), [MariaDB](https://mariadb.org) | Oracle, MS SQL | Thousands of universities |
| Electronics (ECE) | [KiCad](https://www.kicad.org) | Altium, Eagle | [CERN](https://home.cern/news/news/knowledge-sharing/cerns-kicad-component-library-now-open-source), multiple universities |
| Electronics (ECE) | [ngspice](https://ngspice.sourceforge.io), [QUCS-S](https://ra3xdh.github.io/) | PSpice, LTspice | Research labs, [IIT Madras](https://www.ee.iitm.ac.in/~nagendra/cadinfo.html) |
| Electronics (ECE) | [GNU Radio](https://www.gnuradio.org) | NI LabVIEW RF | Research labs globally |
| Mechanical | [FreeCAD](https://www.freecad.org) | SolidWorks, AutoCAD | Growing academic adoption |
| Mechanical | [OpenFOAM](https://www.openfoam.org) | ANSYS Fluent | [TU Delft](https://doc.dhpc.tudelft.nl/delftblue/howtos/openfoam/), [Cambridge](https://www.maths.cam.ac.uk/computing/software/openfoam), [IISc](https://www.serc.iisc.ac.in/compilers-and-libraries/) |
| Mechanical | [Salome Platform](https://www.salome-platform.org) | CATIA | European engineering universities |
| Civil | [QGIS](https://qgis.org) | ArcGIS | [UN](https://www.un-spider.org/links-and-resources/gis-rs-software/qgis) and [hundreds of universities](https://www.qgis.org/project/case-studies/) |
| Civil | [OpenSees](https://opensees.berkeley.edu) | SAP2000 | [UC Berkeley](https://opensees.berkeley.edu) (origin) |
| Civil | [GRASS GIS](https://grass.osgeo.org) | Esri suite | [UMass Amherst](https://www.umass.edu/geological-survey/resources/grass-gis) |
| Design | [Inkscape](https://inkscape.org) | Adobe Illustrator | Design schools globally |
| Design | [Krita](https://krita.org), [GIMP](https://www.gimp.org) | Photoshop | Animation and art schools |
| Design | [Blender](https://www.blender.org) | Maya, 3ds Max | [Blender Institute](https://www.blender.org/institute/), [SUNY Buffalo State Uni](https://suny.buffalostate.edu/news/buffalo-state-offers-design-students-opportunity-learn-blender-3d-animation-industrys-leading) |
| All branches | [LibreOffice](https://www.libreoffice.org) | MS Office | [Kerala KITE](https://kite.kerala.gov.in/KITE/index.php/welcome/downloads) |
| All branches | [Moodle](https://moodle.org) | Proprietary LMS | [Top Universities around the globe](https://moodle.org/mod/forum/discuss.php?d=446423) |
| Research | [Zasper](https://zasper.io/) | MATLAB notebooks | FOSS United Recommendation|
| Research | [R](https://www.r-project.org), [GNU Octave](https://octave.org) | MATLAB, SPSS | Most research universities |
| Administration | [ERPNext](https://erpnext.com) / [Frappe](https://frappe.io) | SAP, Oracle ERP | [Educational institutions in India](https://frappe.io/erpnext/for-education) |
| Administration | [Nextcloud](https://nextcloud.com) | Proprietary cloud storage | [Universities across Europe](https://nextcloud.com/education/) |
| Administration | [Mattermost](https://mattermost.com) | Slack, Teams | Self-hosted by organisations globally, including FOSS United |
